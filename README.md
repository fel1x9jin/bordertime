# BorderTime
  在线访问：https://bordertime.vercel.app
旅客共享的全球机场出入境边检排队时间。出发前看一眼，通过边检后也记一笔，
帮后面的人少排一会儿。

> 当前是 **第一阶段**：只使用本地模拟数据，没有后端，也没有账号系统。

## 数据规则

- 所有时间都是**旅客自己报告的排队耗时**，不是官方验证的实时数据。
- 计时从「排到队尾」开始，到「通过边检」结束，总耗时是**用户报告的排队耗时**，包含窗口办理时间。
- 用户可以选择在走到窗口前点「我到窗口了」，这样报告里会把排队和窗口办理分开记录。
  预计等待时间目前仍按总耗时计算，不混用拆分数据。
- 只有最近 3 小时内的报告计入估算，估算值取这些报告的**中位数**。
- 没有报告时显示「暂无数据」，不会生成假的实时数据。
- 界面中标有「模拟示例」的报告来自 `src/data/mockReports.ts`，仅用于演示。
- 你在浏览器里提交的报告只保存在本机（localStorage），不会上传。

## 运行

需要 Node.js 18.18 或更新版本。

```bash
npm install
npm run dev
```

然后在浏览器打开 http://localhost:3000 。

其他命令：

```bash
npm run typecheck   # TypeScript 类型检查
npm run build       # 生产构建
```

### 用手机预览

电脑和手机连同一个 Wi-Fi，电脑上运行 `npm run dev -- -H 0.0.0.0`，
手机浏览器打开 `http://电脑的局域网IP:3000`。

## 连接 Supabase（可选）

不配置也能运行，会进入本地演示模式。要保存真实报告：

1. 在 [Supabase](https://supabase.com) 新建一个免费项目。
2. 在 SQL Editor 中运行 `supabase/schema.sql`。
3. 复制 `.env.example` 为 `.env.local`，填入项目的网址和 publishable key。
4. 重启 `npm run dev`。

连接后不再显示任何模拟数据；没有报告的机场显示「暂无数据」。

`schema.sql` 里还包含防刷限制：同一个网络 10 分钟内最多提交 6 条报告，超过时数据库会拒绝并返回 `rate_limited`，网页会提示「提交太频繁」。为此数据库会保存一个加盐处理、无法还原成网络地址的标识，24 小时后自动清理。
`.env.local` 已被 `.gitignore` 排除，不要把它提交到仓库，也不要把 secret / service_role 密钥放进前端代码。

## 项目结构

```
src/
  app/                 页面（首页、机场详情页）
  components/          界面组件（机场列表、计时器、报告列表等）
  data/                机场列表和模拟报告
  lib/                 类型、统计、搜索、本地存储、读取报告的 hook
```
